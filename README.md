# Chess Coach — Animated Edition

Open `index.html` in a modern browser.

Features:
- Working chessboard with legal moves via chess.js
- Animated character coach drawn as SVG (not emoji)
- Coach reactions: happy, calm, concerned, angry, brilliant
- 1–5 star move-quality feedback
- Five-star move triggers a kiss animation
- Move list, undo, board flip, new game, coach hint
- Responsive phone layout

Note: chess.js is loaded from a CDN, so the first load needs internet access.
